# 16:9 variant: composition `Film169` (1920x1080, 60 fps, 1080 frames)

Goal: the SAME film (same scenes, timing, score) reframed for 16:9, for the marketing homepage. The 1920x1484 `Film` composition must stay pixel-identical (regression check: `remotion still Film --frame=N` before/after for N in 0, 120, 345, 540, 700, 905, 1000 must be identical).

## Architecture

- Design space stays 1920x1484. The world (scenes A to D), SlotWords and Cursor render inside a **stage** div (1920x1484, `transform-origin: 0 0`) transformed by a per-frame **framing**:
  `output = (design - (960, cy)) * s + (960, 540)`, i.e. CSS `translate(${960 - 960*s}px, ${540 - cy*s}px) scale(${s})`.
- Ground (+ static grain), FrameLine and Rulers render in OUTPUT space at the composition size (read `useVideoConfig()` width/height instead of the W/H constants). FrameLine stays a 1 px `#E8E8E8` rect inset 72 px of the output frame.
- Rulers: camera parallax uses the combined transform (framing composed with the scene camera); the selection extent bands are the scene selection rect mapped through the framing.
- `src/lib/viewport.tsx`: a React context `Viewport = { s, cy, visible: Rect (design coords of the output frame), frameLine: Rect (design coords of the output frame line) }`. Default (Film, no framing) = visible (0,0,1920,1484), frameLine (72,72,1848,1412), s 1, cy 742. Scenes use `useViewport()` wherever they currently assume the 1920x1484 frame edges:
  - SceneB whip column (`height: 1484`, the `-mx` inner 1920x1484 box): span `visible` vertically so the column reaches the output top and bottom edges.
  - SceneB guide lines (`height: 1484`) and any guide that extends a frame edge "to the frame line" (look in B/Frame.tsx and elsewhere for 72 / 1848 / 1412 or full-height lines): extend to `frameLine` in design coords so, on screen, they end exactly on the output frame line.
  - Wall culling (`x > -200 && x < 2120 && y < 1484`, `onScreen` checks): use `visible` (with the same margins) so no tile pops at the wider 16:9 edges. Make sure the wall rows have enough repeats to cover `visible` at s = 0.95 during the whole marquee + whip (no exposed row ends).
  - Rail: make sure cards exist far enough left/right to cover `visible` at s = 0.93 (no empty side where a neighbour card should be).
  - Anything else that is "full bleed" by assuming 0..1920 or 0..1484 (cell reveal, backgrounds, clip boxes W x H with overflow hidden): check each one on the 16:9 render.
- `Root.tsx`: add `<Composition id="Film169" component={Film} defaultProps={{ aspect: "16:9" }} width={1920} height={1080} ... />`. `Film` takes an optional `aspect` prop; `"16:9"` enables the framing; default keeps today's behaviour exactly.
