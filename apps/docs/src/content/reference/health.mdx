---
title: "Health"
description: "Check server and database availability"
---

**Self-hosted only.** Not available on Cloud.

Two probes. `GET /health` is a public liveness check, `GET /health/database` needs an API key and reports on the database.

```bash
curl https://media.example.com/health
```

## Server health

```
GET /health
```

**Auth:** Public (rate limited)

Quick liveness check, use this for load balancer health probes or uptime monitoring.

```json
{
  "status": "ok",
  "timestamp": "2024-03-15T10:30:00.000Z",
  "service": "openinary-api"
}
```

**Status codes:** `200` healthy

## Database health

```
GET /health/database
```

```bash
curl https://media.example.com/health/database \
  -H "Authorization: Bearer <api_key>"
```

**Auth:** API Key required

Detailed diagnostic: checks the database connection and counts the records in every table. On SQLite (the default) it also reports the file's path, size and permissions. On [Postgres](/configuration/database) the tables are listed from `information_schema` for the current schema, and the response never includes the connection URL, which can carry credentials.

```json
{
  "status": "ok",
  "timestamp": "2024-03-15T10:30:00.000Z",
  "database": {
    "connected": true,
    "dialect": "sqlite",
    "path": "/app/data/auth.db",
    "size": "2.4 MB",
    "permissions": "644",
    "tables": {
      "user": 1,
      "session": 3,
      "account": 1,
      "verification": 0,
      "apiKey": 2
    }
  }
}
```

| Field                        | Type      | Description                                                                             |
| ---------------------------- | --------- | ----------------------------------------------------------------------------------------- |
| `database.connected`         | `boolean` | Whether the database connection is active                                               |
| `database.dialect`           | `string`  | `sqlite` or `postgres`                                                                  |
| `database.path`              | `string`  | SQLite only. Absolute path to the database file                                         |
| `database.size`              | `string`  | SQLite only. Database file size                                                         |
| `database.permissions`       | `string`  | SQLite only. Octal file permissions, three digits with no leading zero (for example `600` or `644`) |
| `database.tables`            | `object`  | Record counts per table. Useful for verifying migrations applied correctly              |
| `database.warning`           | `string`  | SQLite only. Present only when the database file is larger than 1 GB. Permission problems are reported in `security_warning` instead |
| `database.security_warning`  | `string`  | SQLite only. Present when the database file's permissions are less restrictive than `600`             |
| `database.file_error`        | `string`  | SQLite only. Present if the database file's permissions or size couldn't be read                     |
| `database.table_error`       | `string`  | Present if table record counts couldn't be retrieved                                    |

**Status codes:** `200` healthy · `503` database connection failed
