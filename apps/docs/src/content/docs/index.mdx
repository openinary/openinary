---
title: "Openinary"
description: "Open-source alternative to Cloudinary. Resize, crop, convert and deliver images and video on the fly, from a URL. Hosted or self-hosted."
---

Upload a file once, then change the URL to change the file.

```http
GET /t/photos/portrait.jpg                              the original
GET /t/w_400,h_400,c_fill/photos/portrait.jpg           a 400x400 crop
GET /t/w_400,h_400,c_fill,f_avif/photos/portrait.jpg    the same, as AVIF
```

Each variant renders on first request and is cached from then on. Nothing is pre-processed, and you never write a resizing pipeline.

Two ways to run it, one API. [Openinary Cloud](/cloud/overview) is the hosted version: create an account and start uploading, nothing to operate. Sign-up is open at [app.openinary.dev](https://app.openinary.dev). Or [self-host](/quickstart) it with Docker and keep your infrastructure and data entirely yours.

## Features

| | |
| --- | --- |
| **URL transformations** | Resize, crop, rotate, round, convert and trim, for images and video |
| **Automatic formats** | AVIF or WebP when the browser takes it, JPEG or PNG otherwise |
| **Caching** | Every variant renders once, then comes from cache |
| **S3-compatible storage** | AWS S3, Cloudflare R2, MinIO, DigitalOcean Spaces, or local disk |
| **Signed URLs** | Restrict delivery to the transformations your backend authorized |
| **Two modes** | Full stack with a dashboard, or headless API-only |
