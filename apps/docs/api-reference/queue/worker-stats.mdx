---
title: "Worker Statistics"
description: "Current state of the background video processing worker"
---

**Self-hosted only.** Cloud exposes `/queue/events` only.

Reports what the background worker is doing right now: its limits, and how many jobs it is running.

```bash
curl http://localhost:3000/queue/worker/stats \
  -H "Authorization: Bearer <api_key>"
```

```
GET /queue/worker/stats
```

**Auth:** API Key required

## Response

```json
{
  "maxConcurrent": 2,
  "pollInterval": 1000,
  "isRunning": true,
  "processingCount": 1
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `maxConcurrent` | number | Maximum number of jobs the worker processes at once |
| `pollInterval` | number | How often, in milliseconds, the worker polls for new jobs |
| `isRunning` | boolean | Whether the worker's polling loop is currently active |
| `processingCount` | number | Number of jobs currently being processed |
