---
title: "Download Original File"
description: "Download the original uploaded file without any transformation"
---

Point at the storage path and the original bytes come back as an attachment.

```
GET /download/{path}
```

```bash
curl -O -J http://localhost:3000/download/photos/portrait.jpg
```

**Auth:** Public (rate limited)

## Path parameters

| Param  | Type     | Description                                                                              |
| ------ | -------- | ---------------------------------------------------------------------------------------- |
| `path` | `string` | Required. Path to the file relative to the storage root, including the extension (`videos/clip.mp4`) |

## Response

Returns the raw binary content of the original file with `Content-Disposition: attachment`, so browsers prompt a download rather than displaying it inline.

| Header                | Value                               |
| --------------------- | ----------------------------------- |
| `Content-Type`        | Detected from file extension        |
| `Content-Disposition` | `attachment; filename="{filename}"` |
| `Content-Length`      | File size in bytes                  |
| `Cache-Control`       | `private, no-store`                 |

**Status codes:** `200` success · `400` invalid path · `404` not found · `500` error
