---
title: "Download Folder as ZIP"
description: "Download every file under a folder as a single ZIP archive"
---

**Self-hosted only.** Not available on Cloud.

Point at a folder path and get one ZIP back, no list of files needed.

```
GET /download-folder/{path}
```

```bash
curl -O -J https://media.example.com/download-folder/photos
```

**Auth:** Public (rate limited)

## Path parameters

| Param  | Type     | Description                                                            |
| ------ | -------- | ---------------------------------------------------------------------- |
| `path` | `string` | Required. Path to the folder relative to the storage root (`videos/2024`) |

## Response

Returns a ZIP archive containing every file under the folder, recursively. Each entry's path is preserved relative to the folder.

| Header                | Value                                     |
| --------------------- | ----------------------------------------- |
| `Content-Type`        | `application/zip`                         |
| `Content-Disposition` | `attachment; filename="{folderName}.zip"` |
| `Content-Length`      | Archive size in bytes                     |
| `Cache-Control`       | `private, no-store`                       |

**Status codes:** `200` success · `400` missing or invalid path · `404` folder not found or empty · `500` error
