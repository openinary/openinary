---
title: "List Folders"
description: "Get every folder path in storage, for building a folder picker"
---

Returns every folder path in storage in one call, which is what powers "Move to" folder pickers.

```
GET /storage/folders
```

```bash
curl https://cdn.openinary.dev/storage/folders \
  -H "Authorization: Bearer <api_key>"
```

**Auth:** API Key required

## Response

```json
{
  "folders": ["archive", "photos", "photos/2024"]
}
```

| Field     | Type       | Description                                                             |
| --------- | ---------- | ----------------------------------------------------------------------- |
| `folders` | `string[]` | Every folder path, relative to the storage root, sorted alphabetically. |
