---
title: "Local Development"
description: "Run the Openinary monorepo from source, with the API on :3000 and the dashboard on :3001."
---

Clone, install, run:

```bash
git clone https://github.com/openinary/openinary.git
cd openinary
pnpm install
pnpm dev
```

`pnpm dev` starts both services in parallel.

| Service       | URL                   |
| ------------- | --------------------- |
| API           | http://localhost:3000 |
| Web dashboard | http://localhost:3001 |

Run them one at a time with `pnpm dev:api` (:3000) or `pnpm dev:web` (:3001).

## First run

Visit **http://localhost:3001** and you are redirected to `/setup` to create your admin account. Once logged in, open **API Keys** from the bottom-left profile menu to generate your first key.

## Prerequisites

| Tool    | Version    | Notes                            |
| ------- | ---------- | -------------------------------- |
| Node.js | ≥ 20.0.0   | `node --version` to check        |
| pnpm    | ≥ 9.0.0    | `npm install -g pnpm` to install |
| FFmpeg  | any recent | Required for video processing    |

## Run with Docker Compose

Prefer containers? Use the compose profiles instead:

```bash
# Full stack (API + dashboard)
docker compose --profile full up --build

# API only
docker compose --profile api up --build
```

## Storage

Uploaded files land in `apps/api/public/` by default. For cloud storage, set the [`STORAGE_*` variables](/configuration/storage) in `apps/api/.env`.
